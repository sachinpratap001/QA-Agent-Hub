## Steps to Reproduce
1. Log in, add a product to the cart, proceed to checkout.
2. Fill the shipping address with a malformed postal code (e.g. `@@@`).
3. Click continue.

## Expected
Form rejects the postal code with a validation message (gemini.md §3.2: `postal_code` required).

## Actual
Form accepts the value and moves to the next step.
